Technical Blueprint

System Architecture

Stack & Infrastructure

Frontend
React 18 + TypeScript. TanStack Router for file-based routing. TanStack Query for server state. Tailwind CSS. Vite build tool.
React 18TypeScriptTailwindVite
Backend
Node.js + Fastify REST API. JWT authentication with hotel_id claim. Tenant middleware isolates data per slug on every request.
Node.jsFastifyJWTZod
Database
PostgreSQL with Row-Level Security (RLS). hotel_id column enforces tenant isolation at DB level. Drizzle ORM for type-safe queries.
PostgreSQLRLSDrizzle ORM
Infrastructure
Docker containers. Nginx reverse proxy with SSL termination. Cloudflare CDN + WAF. S3 object storage for hotel images.
DockerNginxCloudflareS3

Security Model

Layer 1 — JWT: Every auth token carries hotel_id. Middleware verifies this claim on every admin API request before touching the DB.
Layer 2 — PostgreSQL RLS: Row-Level Security policies on all tenant tables ensure even direct DB queries can only access rows where hotel_id matches the session context. Defense in depth.
Layer 3 — Role Enum: super_admin bypasses hotel_id check (with separate secret). hotel_admin has full CRUD on own hotel. staff role is read-only.
Layer 4 — Rate Limiting: Fastify rate-limit plugin on booking and auth endpoints. Cloudflare DDoS protection at edge.
Subscription Gate: Middleware checks subscription_status on every hotel_admin request. Expired = 402 response. Public-facing routes (hotel website, explore) remain accessible with a renewal banner shown.
